# Basic Learning Codes

This repository is a simple collection of beginner-friendly Python exercises I created while learning the basics of programming at university.

## What is in this repository?

This project contains small Python programs focused on fundamental concepts, including:

- name_and_dream.py — Printing personal information such as name and dream
- strings.py — Working with Python strings
- even_odd.py — Checking even and odd numbers
- student_gwa.py — Processing student GWA data from text files
- multiple_lines.py — Reading and handling multiple lines of text

## Purpose

The goal of this repository is to keep my early learning exercises organized and easy to review as I improve my coding skills.

## Technologies

- Python
- Basic file handling
- Beginner-level programming exercises

## Notes

This repository is intended for learning and practice, not for advanced applications.
